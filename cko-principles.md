# cko principles

cko makes minimal apps: stripped down to only the functionality, in black and white.

## Only the functionality
- Each app does one job. Nothing beyond what that job needs.
- If the app works without a feature, the feature is left out.
- Small and light. No install, no background work, nothing running when idle.
- No network, files or registry unless the job needs them.

## Black and white
- Black background, white text and lines. No color, no gradients.
- Lowercase by default.
- One heading, the controls, one small hint line. Nothing else on screen.

## Names
- One plain lowercase word per app: `click`, `timer`, `note`.
- Repository `cko-<word>`, app `<word>.exe`.

## Trust
- Open source, MIT license.
- Builds are reproducible: the code always produces the same file.
- Checked against antivirus before every release.
